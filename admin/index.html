الاتصال بالمستودع

الموقع ثابت على GitHub، لذلك تحفظ اللوحة التعديلات بإنشاء commit مباشرة في المستودع (ملفات data/products.json وصور المنتجات). يلزمك مرة واحدة إنشاء توكن.

كيف أنشئ التوكن؟
  1. GitHub ← Settings ← Developer settings ← Personal access tokens ← Fine-grained tokens ← Generate new token.
  2. Repository access: Only select repositories واختر مستودع الموقع فقط.
  3. Permissions ← Repository permissions ← Contents: Read and write.
  4. انسخ التوكن والصقه هنا. يُحفظ في متصفحك فقط ولا يُرسل إلا إلى api.github.com.

أي شخص يفتح هذه الصفحة بدون التوكن لا يستطيع تعديل شيء. استخدم "مسح التوكن" إذا كان الجهاز مشتركاً.

اللوحة تدير منتجات الأقسام الموقع. أقسام الترند والأكثر مبيعاً والخصومات تُبنى تلقائياً من المنتجات.
